仍須在真實手機檢查下列項目，模擬器成功不代表全部品牌已驗證：

- 飛航模式首次開 App、同意、新增學員、重開後資料仍在。
- 系統檔案選擇取消與成功匯入；直拍／橫拍 MP4、變動幀率、左右手影片。
- 3 分鐘及 300 MiB 邊界；損壞影片、空間不足、解碼器不支援有清楚提示。
- 0.25 倍播放、前後逐格、首尾格、時間與影格一致。
- 畫線、撤銷、清除、放棄確認、保存及重開；匯出系統選檔取消／成功。
- 七項評估存檔、練習配對、改善紀錄持久化、刪除影片不刪除既有評估。
- 刪除學員清除本機相關紀錄；已匯出的圖片保留。
- 字體放大、螢幕旋轉、背景暫停、手機程序被系統收回。
- release 不要求網絡或媒體庫權限，最近使用畫面與系統截圖受保護。

不使用真實兒童資料上傳測試；整合測試影像是程式產生的色彩圖案。


## 1.2 自動分析實體裝置驗收（待執行）

- 首次安裝即開飛行模式，匯入全身單人影片，確認模型毋須網絡初始化。
- 先用 5–15 秒、固定鏡頭影片，涵蓋準備及揮拍後兩秒；確認進度、報告、時間點及骨架對齊。
- 左手、右手、鏡像分別對照；橫拍、直拍及帶旋轉 metadata 的片段核對方向。
- 多人、遮擋、背面、暗光、移動鏡頭、缺腳及非羽毛球動作；核對是否棄用或標示不足，人工記錄誤報。
- 取消、返回、切到其他 App、鎖屏後重試，確認沒有殘留分析、重複計劃或部分報告。
- 關閉重開仍能讀報告；刪除影片後姿態資料消失，已加入練習計劃保留。
- 與經適當同意的兒童動作人工標註比較；沒有這些資料前不公布球技準確率。
- 此測試簽署版不能保證直接覆蓋上一個 runner 的 APK；有資料時不要為解決簽章問題直接解除安裝。
