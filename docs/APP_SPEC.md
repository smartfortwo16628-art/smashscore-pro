# V1 開發規格與架構

## 交付範圍

Android 9+；Flutter／Dart；離線免費；繁體中文及廣東話教學。V1 重點是教練可操作的影片檢視、記錄及改善流程。後續 ML Kit 不阻礙 V1 安裝使用。

## 頁面流程

首次同意與私隱說明 → 訓練室／學員／影片／練習四分頁。

- 訓練室 → 六項技術教學、評估界線、使用說明、開源授權。
- 學員 → 新增／修改／刪除 → 檔案 → 影片、七項評估、歷次觀察、計劃。
- 影片 → 選學員 → Android 系統選檔 → 私人複製 → 播放、慢放、時間軸 → 逐格／畫線 → 保存 → 查看／匯出。
- 評估 → 準備姿勢、手肘、肩膊、轉身、擊球點、腳步、平衡逐項選擇「未能觀察／表現穩定／需要練習」→ 問題選擇 → 規則配對至多三項練習。
- 練習 → 口令／練法 → 已完成項目 → 控制動作自評 1–5 及備註 → 改善紀錄。

表單有驗證、進行中狀態、錯誤處理；刪除及放棄畫線須確認。所有可見按鈕有實際動作。看不清必須記為未能觀察，沒有虛構分數。

## 資料模型

| 資料表 | 主要欄位 | 關係與生命週期 |
|---|---|---|
| settings | key, value | 本機初次同意 |
| students | id, name, age, hand, experience, notes, created | 暱稱，不收生日、電話 |
| videos | id, student_id, title, path, duration_ms, created | 私人副本；學員刪除連帶清除 |
| snapshots | video_id, path, position_ms, frame_index, strokes, created | PNG 與正規化畫線座標 JSON |
| assessments | student_id, video_id?, ratings, issues, notes, created | 刪除影片保留評估、解除連結 |
| plans | student_id, assessment_id?, drill_ids, created | 與評估同交易寫入；至多三練習 |
| practices | plan_id, completed, effort, notes, created | 保存每次練習與改善備註 |
| garbage | path | DB 刪除交易先排程檔案清除，失敗下次重試 |

UUID 型隨機 ID、UTC 時間；顯示時轉裝置時區；外鍵強制啟用及級聯；有相關索引。SQL 查詢使用參數。DB schema version 1，後續遷移須使用 onUpgrade，禁止直接清除使用者資料。

## 技術架構

- `main.dart`：初始化、私隱同意、依賴提供、語言及主題。
- `screens.dart`：教學、學員、人工評估、練習及紀錄。
- `coaching.dart`：獨立教學內容與有上限的練習配對規則。
- `store.dart`：SQLite、交易、外鍵、檔案垃圾清理、UI 更新通知。
- `video.dart`：video_player、原生 MethodChannel、逐格及畫線保存。
- `MainActivity.kt`：SAF 匯入／匯出、背景執行、MediaExtractor 時間戳、MediaMetadataRetriever 真實索引解碼、私有路徑驗證。

影片採實際樣本呈現時間排序，不以平均 FPS 計算索引。總數或時間戳有疑問則停用逐格、改為明示近似擷取。逐格 API 失敗會報錯，不靜默改成其他影格。只保留四段影片的索引快取；截圖最大邊 1280；匯入最多 3 分鐘／300 MiB／16MP。

## 正手高遠球評估界線

| 問題 | 影片可記錄的特徵 | 教練判斷 | 不可靠自動判斷 |
|---|---|---|---|
| 握拍 | 近鏡可觀察手指外形 | 虎口、鬆緊、握法是否適合 | 普通全身片的指力、拍柄接觸 |
| 準備 | 側身、腳位、動作次序 | 來球下的準備時機 | 缺少羽毛球時的到位精確度 |
| 手肘／肩 | 清晰鏡頭平面下的路徑 | 舒適幅度、協調 | 真實 3D 關節角、內外旋 |
| 轉身 | 轉動先後與落地補步 | 轉幅是否過大 | 單鏡頭真實 3D 轉身角 |
| 擊球點 | 有清晰球拍與波才可人工定位 | 是否適合來球與目的 | 只靠人體骨架確認接觸瞬間 |
| 平衡 | 額外踏步、站穩時間 | 補步是否必要、是否可控制 | 壓力中心、受力、傷患診斷 |
| 剪刀步／回位 | 腳次序、指定區回位時間 | 情境需否剪刀步、回位區 | 缺少對手／場地資訊的戰術正確性 |

上述可記錄特徵是人工逐格觀察範圍；V1 沒有自動角度量度或動作辨識。

## 後續階段

階段二加入獨立 `PoseAnalyzer` 服務，輸入本機解碼影格，輸出時間戳、關節座標、信心、缺失標記及鏡頭平面量度；ML Kit 選用裝置端套件，先驗證模型可完全離線初始化，再暴露 UI。ML Kit SDK 並非全開源，須另記授權。

驗證資料必須經家長同意、涵蓋左右手、遮擋、不同視角、兒童身高及手機；與人工標註比較時間／座標誤差，低信心不給評語；不可用成人統一角度診斷小朋友。測試報告通過前不稱為已驗證 AI。

第三階段雲端備份及 GPT 需獨立 opt-in、可撤回、明示傳出資料及費用。V1 沒有 API 金鑰欄、上傳端點、網絡權限或假按鈕；不可把秘密金鑰硬編碼進 APK。

## 驗收

每個階段對應程式檔案、測試及 CI 輸出：規格／介面／完整本機功能／Android build。姿態辨識仍是未實作的下一階段。真正 APK 必須由成功 CI、apksigner 與 manifest 檢查確認，不以畫面或 ZIP 原始碼冒充。
